# Contributing

Issues and pull requests are welcome. This repository is independent of NostrMash Core and SmartFlowSocial.

1. Use Node.js 22 or newer and pnpm 12.21.0.
2. Run `pnpm install`.
3. Run `pnpm validate` before opening a pull request.
4. Do not commit `.dev.vars`, tokens, or Cloudflare credentials.
5. Use a GitHub noreply address for commits.

The Unlicense applies to contributions. There is no contributor license agreement. Do not add code copied from a repository that has no license.

# Security reports

Use [SECURITY.md](SECURITY.md). Do not open a public issue for a vulnerability.
